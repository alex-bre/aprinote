Getting Started

The whole app in one page: three modes, one document, and a folder of real files underneath it.

The three modes

  1. Edit — the WYSIWYG surface. What you type becomes ordinary HTML.
  2. Source — the full file, head and all. Edits here land in the same document the editor is holding.
  3. Preview — the page as a reader gets it, at a real device width.
Switch modes with the segmented control in the top bar. The document never round-trips through a different format on the way — all three views are the same file.

Shortcuts worth knowing

KeysWhat happens
⌘KSearch pages, page text and commands. With text selected, it links instead.
/The slash menu, at the start of an empty paragraph.
⌘B ⌘I ⌘UBold, italic, underline.
⌘SSave the vault stylesheet. Pages autosave on their own.
TabNest a list item; move to the next table cell.

Markdown-ish input rules

  • Type - for a bullet, 1. for a number
  • Type ## through ##### for headings 2–4
  • Type > for a quote, --- for a divider
