Links & Backlinks

Every other page in this vault links here, so the backlinks panel has something to show. Open the inspector to see them.

What a page link is

<a data-aprinote="pg_dm05" href="block-gallery.html">Block Gallery</a>

data-aprinote is the truth the app resolves against. The href is derived — recomputed on every save, and on any rename or move — so the files stay clickable as a plain static site while the app never depends on them.

What that buys

You doThe vault does
Rename a pageRenames the file, rewrites every inbound href, and updates the link text wherever it still matched the old title
Move a page to another folderRecomputes its ../ depth for assets and links, in one write
Move a whole folderThe same, for every page underneath it
Give a link your own wordsLeaves them alone on rename — a hand-written label is a decision

Try it

  1. Rename Block Gallery from the sidebar
  2. Watch this page's link text follow it, and the file on disk change name
  3. Drag it into Handbook and check the source view: the href has grown a ../
An id that resolves to nothing keeps its last known href rather than being blanked. A dangling link degrades into an ordinary broken one instead of vanishing.
