Tables

Plain <table> markup with no wrapper divs, no data attributes and no state kept outside the file.

The default shape

A fresh table is 3×2 with a header row: one <tr> of <th>, then <td> rows. Tab moves to the next cell, Enter at the end of the last row adds another.

GestureResult
Hover a column edgeHandles to insert, delete or drag that column
Hover a row edgeThe same, for rows
Drag a boundaryWrites column widths as a <colgroup>

Banded rows

The zebra switch adds one class. The stripe itself is a rule in the vault stylesheet, so a reader opening the file off disk sees the same bands.

Declared column widths

Dragging a boundary writes percentages into a <colgroup> and pins table-layout: fixed, without which a browser is free to ignore a width whenever the content wants more room. Distribute removes both again.
