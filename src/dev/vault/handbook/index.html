Why a folder gets an index page

A vault is a website. A folder with no index.html is a directory listing when someone points a server at it; a folder with one is a page. The sidebar offers Add index page on any plain folder — reference/ is left without one so the affordance has somewhere to land.

How the linking underneath all this works is its own page: Links & Backlinks.

Retitling an index page never renames the folder. That would move every file underneath it, and break every href on the way.
