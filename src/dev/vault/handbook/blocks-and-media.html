Blocks & Media

The blocks that are more than a paragraph: callouts that hold other blocks, images with constraints, embeds, and the gutter that moves them all around.

Callouts hold blocks

A callout of plain inline text stays exactly that — a <div class="callout"> with words in it.

Press Enter inside one and it comes into block form around the caret.

  • A list can live in here
  • So can a heading, an image, or a table

Its background is its own — set from the inspector, written as an inline style, and independent of the vault stylesheet's default.

Drop a block onto a callout and it moves into it. Drag it out by aiming at a gap between two blocks in the document.

Columns

Type /columns and pick two or three to lay blocks side by side. A layout is a <div class="columns"> holding one <div class="column"> per column, and each column holds blocks just like a callout. On a phone-width screen they stack.

Before

Each column is its own little document. Enter adds a line inside it; Enter on an empty last line steps out below the whole layout.

  • Lists work
  • So do headings

After

Backspace at the top of a column stops there, so one column never spills into its neighbour.

A callout can sit in a column, too.

Each column is a container, so a figure and its text travel together.

Images fill their column and scale with it.

Switch preview to 390 and the three of these stack.

With the caret in a layout, the inspector sets how many columns it has. Taking columns away moves their blocks into the last one kept, and choosing 1 dissolves the layout back into ordinary blocks. Drag a column's handle to reorder it, or drop a block between two columns to make a new one.

Images

An image is a <figure> holding an <img> and a <figcaption>. Drag a file onto the page and it lands in _assets/ with a readable name; the src is written at the page's own depth, so this page — one folder deep — refers to ../_assets/….

Deleting a page never deletes an asset — any image may be referenced from anywhere. Settings has a sweep for the ones nothing points at any more, and this vault ships one on purpose: _assets/unused-sketch.svg.

Embeds

An embed is an <iframe> in a figure. While you are editing it is inert — the URL is parked in data-aprinote-src and the frame is never fetched, so a page full of embeds stays fast and cannot steal the caret. Preview renders the real thing.

Quotes, code and dividers

A blockquote is a <blockquote>. Because pages are plain HTML documents, anything valid can live in one.
// A code block is a <pre><code> — never formatted, never linkified.
const vault = await open('~/notes')
<a data-aprinote="pg_dm00">stays literal in here</a>

Above this paragraph is an <hr>. Type --- on an empty line to get one.

Moving blocks

  1. Hover the left gutter — every block gets a handle
  2. Drag it to a gap between two blocks, or onto a callout to drop it inside
  3. Select several blocks first and the handle drags the whole set, in document order

The full catalogue is over in the Block Gallery; tables get a page of their own in Tables.
