Writing & Formatting

Everything the floating toolbar can do to text, with the HTML each gesture produces.

Body text carries the marks you would expect: bold becomes <strong>, italic becomes <em>, underline becomes <u>, and they stack — all three at once. Inline code is a plain <code>.

Colours come from the vault palette in _vault/vault.json, so a document can only ever use colours the vault knows about: blue text, green text, orange text, a blue background, an orange one, and both together.

Alignment

Left is the default, and writes no style at all.

Centered — style="text-align:center" on the block.

Right-aligned.

Justified, which only shows itself once a paragraph runs past a single line, as this one does — the lines stretch to meet both margins, which is worth having for a dense reading column and worth avoiding almost everywhere else.

Lists

  • A bullet list is a plain <ul>
  • Start one by typing - at the head of a paragraph
    • Tab nests, Shift+Tab lifts back out
    • A nested list lives inside the <li> it hangs off, which is what makes it valid HTML
  • Enter on an empty item ends the list
  1. A numbered list is an <ol>
  2. Start one by typing 1.
    1. Numbering is the browser's job, never written into the file
    2. So reordering items renumbers them for free

Links

Three kinds, and they are all just anchors:

  • An external link — an ordinary href
  • A page link — carries data-aprinote, and survives renames
  • A mail link, and anything else a browser understands
Select any text and press ⌘K to link it. With nothing selected, ⌘K is the search palette instead.

Multi-block selection

Drag in the left gutter, or across two blocks, to pick whole blocks rather than text. The gutter handle then drags the whole set — and Backspace throws it away in one step. Blocks & Media has things worth dragging.
